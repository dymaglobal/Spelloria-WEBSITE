# Spelloria Patisserie — Frontend Application

Next.js 16 (App Router) luxury e-commerce application featuring React 19, Turbopack, Tailwind CSS v4, and dynamic Server-Side Rendering (SSR).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Compile production build
npm run build

# Start production server
npm run start

# Run linter
npm run lint
```

For complete platform documentation, architecture overviews, and Hostinger Cloud Startup deployment instructions, refer to the [Root README](../README.md).
